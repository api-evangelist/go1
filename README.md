Go1 is an AI-powered corporate learning and development (L&D) platform that consolidates employee training into a single subscription. Its content library aggregates courses from 250+ providers across 40+ languages, layered with curation, skill-based learning paths, reporting and the Morgan by Go1 learning agent, and connects to existing HR and business systems through 75+ integrations. The Go1 developer platform exposes a date-versioned REST API (gateway.go1.com, Api-Version header) for discovering learning objects, managing enrollments, provisioning customer portals and subscribing to events via webhooks, secured with OAuth 2.0, plus JavaScript/React embedding SDKs and a webhook-verifier library. Go1 is backed by SoftBank Vision Fund and Y Combinator.

**Areas:** Company · EdTech · Learning · E-Learning · Corporate Training · Content · LMS · Education · Webhook

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Go1: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
